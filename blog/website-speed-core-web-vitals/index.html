How Fast Should Your Website Load?

"Make it faster" is easy advice to give and hard to act on without knowing what's actually being measured. Google grades sites on three specific metrics, collectively called Core Web Vitals. Here's what each one means in plain English.

Largest Contentful Paint (LCP) — how long until the main content shows up

This measures the time it takes for the biggest visible element on the page — usually a hero image or heading — to fully load. Google considers 2.5 seconds or faster to be good. Past 4 seconds is considered poor. The most common fix is compressing images and making sure the server responds quickly.

Interaction to Next Paint (INP) — how responsive the page feels

This measures the delay between a visitor clicking, tapping, or typing something and the page actually responding. Under 200 milliseconds is good. Heavy, unoptimized JavaScript is the usual culprit here — the browser is too busy running scripts to respond to input right away.

Cumulative Layout Shift (CLS) — how much the page jumps around while loading

You've felt this one even if you didn't know its name: you go to tap a button, and at the last second an ad or image loads above it and shifts everything down, so you tap the wrong thing. A CLS score under 0.1 is good. The fix is usually reserving space for images and ads before they load, instead of letting the page reflow around them.

Three ways to check your own site right now

  1. PageSpeed Insights (pagespeed.web.dev) — paste in your URL and get real Core Web Vitals scores, plus a prioritized list of what to fix.
  2. Chrome DevTools — right-click any page, choose "Inspect," open the Lighthouse tab, and run an audit directly in your browser.
  3. Search Console — if you have it set up, the Core Web Vitals report shows real data from actual visitors, not just a simulated test.
A site that scores well on all three isn't just ranking better — it's keeping more of the visitors who show up.

The honest bottom line

Perfect scores aren't the goal — "good" across all three, consistently, is what actually matters for both ranking and for visitors sticking around. If your scores are in the red, that's usually a sign of a few specific, fixable issues rather than a site-wide rebuild.
